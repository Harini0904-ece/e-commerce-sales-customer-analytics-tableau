# E-Commerce Sales & Customer Analytics Dashboard

## 📊 Project Overview

An interactive Tableau dashboard designed to analyze e-commerce sales performance, customer behavior, purchasing patterns, and transaction trends.

The dashboard provides a consolidated view of revenue, orders, customers, product categories, cities, payment methods, devices, and customer demographics.

## 🎯 Business Objectives

- Analyze overall sales performance
- Track monthly revenue trends
- Identify high-performing product categories
- Compare city-wise sales performance
- Analyze new vs returning customers
- Understand preferred payment methods
- Analyze device-wise purchasing behavior
- Study sales patterns across different age groups

## 🚀 How to Use

1. Download the `.twbx` Tableau packaged workbook.
2. Open it using Tableau Desktop / compatible Tableau software.
3. Use the Date, City, and Product Category filters.
4. Click cities or product categories to interactively filter the dashboard.
